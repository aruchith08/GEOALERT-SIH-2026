2. MODEL A: STATIC LANDSLIDE SUSCEPTIBILITY MODEL (LSI)
--------------------------------------------------------------------------------
A. Target Variable:
   - Positive Class (1): 1,052 confirmed field-validated GSI landslide occurrences.
   - Negative Class (0): Pseudo-absence candidates sampled with 500m exclusion buffer.

B. Predictor Features (16 Static Geo-Environmental Variables):
   1. elevation (SRTM 30m, meters)
   2. slope (SRTM 30m, degrees)
   3. aspect (SRTM 30m, degrees)
   4. plan_curvature (SRTM 30m, rad/m)
   5. profile_curvature (SRTM 30m, rad/m)
   6. twi (Topographic Wetness Index, dimensionless)
   7. spi (Stream Power Index, dimensionless)
   8. landcover_code (ESA WorldCover 10m integer class)
   9. ndvi_mean (Sentinel-2 MSI 10m annual baseline)
   10. soil_clay_fraction (ISRIC SoilGrids 250m, 0-30cm, %)
   11. soil_sand_fraction (ISRIC SoilGrids 250m, 0-30cm, %)
   12. soil_bulk_density (ISRIC SoilGrids 250m, 0-30cm, g/cm3)
   13. soil_ph (ISRIC SoilGrids 250m, 0-30cm, pH units)
   14. lithology_code (GLiM Hartmann & Moosdorf / GSI, 2-letter code)
   15. distance_to_roads (OSM 27,552 road segments, meters)
   16. distance_to_streams (OSM 3,695 waterway segments, meters)

C. Excluded Attributes (Zero Contamination Safeguard):
   - Identifier columns: source_page, sl_no, slide_no, slide_name, nh_sh_location, state, district, history.
   - Temporal tags: event_date, event_year, temporal_quality.
   - Dynamic rainfall: rainfall_event_day, ari_3, ari_7, ari_15, ari_30, max_1day_7d, max_3day_30d, rainy_days_7d, 15d, 30d.

3. SPATIAL CROSS-VALIDATION & DATA SPLIT STRATEGY
--------------------------------------------------------------------------------
A. Deterministic Spatial Sectors:
   - Block 1: Garo Hills (West/East/South/South-West Garo Hills, Lon < 91.0)
   - Block 2: West Khasi & South West Khasi Hills (91.0 <= Lon < 91.6, Lat < 25.65)
   - Block 3: East Khasi Hills / Shillong Plateau (91.6 <= Lon < 92.0, Lat < 25.65)
   - Block 4: Ri-Bhoi (Northern plateau slopes, Lat >= 25.65)
   - Block 5: Jaintia Hills (East / West Jaintia Hills, Lon >= 92.0, Lat < 25.65)

B. Spatial Train / Validation / Test Partitioning:
   - Training Partition (~60%): Blocks 1, 2, and 4 (Garo Hills, West Khasi, Ri-Bhoi).
   - Validation Partition (~20%): Block 5 (Jaintia Hills). Used for optimal threshold tuning.
   - Test Partition (~20%): Block 3 (East Khasi Hills). Spatially independent holdout test.
   - Leakage Prevention: Zero geographic coordinates or adjacent spatial cells overlap between sets.
